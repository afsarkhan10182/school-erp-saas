## 2026-10-23 — Student edit tenant and academic-placement isolation

- Student update no longer accepts request-supplied `school_id`, `branch_id`, `user_id`, or class-name fields as direct assignments. Partial edits now preserve existing enum values rather than defaulting an omitted status to Active.

The source database still had the original Alex / Main Branch row. Migration check on the source dev DB was a no-op (already current); the isolated test clone and services were removed afterward.
- Student creation now resolves submitted class, section, stream, and academic-year IDs before persistence; placement references must be active and match the chosen school, branch, class, and stream. Caller-supplied `user_id` and denormalized class labels are discarded. Focused create/update/promotion/sibling tests pass **19/19**; creation scope itself was verified with mocked model queries, not a browser-created record.
