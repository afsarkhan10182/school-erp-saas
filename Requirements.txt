## ✅ 1. Multi-Branch & SaaS Architecture (Clarified)

### Super Admin (SaaS Owner)

* Manages **entire platform**: can create and manage **multiple Schools** (tenants) with their own Admins.
* Adds **Schools** with specific **Plans & Packages** (student limits, branch limits, module access).
* Automatically creates **School Admin** login when adding a new School.
* Can create **Branches** for any School or let the School Admin handle it.
* Manages **SaaS billing, subscription status, trial, suspension/reactivation**.
* Can view **consolidated reports across all Schools**.

### School Admin (School Owner/Admin)

* Manages **one School (tenant)** and all its **Branches**.
* Can create **multiple Branches** (physical campuses) under the same School, if allowed by the plan.
* Adds and manages **Staff, Teachers, Receptionists, Accountants, HR, Librarians, Parents, Students**.
* Assigns **Roles & Permissions** to all users under the School.
* Can enable/disable **Modules** (e.g., Library, Hostel, Transport) per role or per user.
* Views **School-wide reports** including all its branches.

### Branch Admin

* Manages **one Branch** (campus) only.
* Can add/manage **Students, Staff, Fees, Attendance, Academics** within their branch.
* Cannot create new Branches or access other branches' data.
* Views **Branch-level reports** only.

### Key SaaS Clarifications:

* **Super Admin = SaaS Platform Owner**: Only role that can create **Schools (tenants)**.
* **School Admin = Customer**: Manages their own **School and Branches**. Cannot create new "Schools".
* **Branch = Physical division** within the same School.

## 🔐 2. Authentication & Role Permissions

| Role          | Scope and Access                                          |
| ------------- | --------------------------------------------------------- |
| Super Admin   | Manages all Schools, billing, system-wide settings.       |
| School Admin  | Manages entire School and its Branches, staff, and roles. |
| Branch Admin  | Manages single Branch data only.                          |
| Accountant    | Manages fees, expenses, payroll.                          |
| HR            | Manages staff, attendance, payroll.                       |
| Receptionist  | Manages admissions, communication.                        |
| Teacher       | Manages classes, exams, homework.                         |
| Librarian     | Manages library books, inventory.                         |
| Transport Mgr | Manages vehicles, routes.                                 |
| Student       | Self-service: timetable, results, payments.               |
| Parent        | Child's data, communication, fee payments.                |
| Alumni        | Limited alumni portal access.                             |

* **Roles can have module-level access control** (e.g., enable Library, disable Hostel).
* **Secure login**: CAPTCHA, session timeout, brute-force protection, optional 2FA.
